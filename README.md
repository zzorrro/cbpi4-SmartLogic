# cbpi4-PIDMash

Умный плагин логики нагрева котла с PID-регулятором и автоматическим переключением на прямой нагрев для CraftBeerPi 4.

## Описание

Гибридная логика нагрева, которая объединяет точность PID-регулятора для этапа затора и эффективность прямого нагрева для остальных этапов варки.

**Главная идея:** PID нужен только для точного удержания температуры затора (например, 62-72°C). До и после этого диапазона PID только мешает — создаёт лишние колебания и замедляет нагрев. Поэтому плагин автоматически переключается между режимами:

- **Вне диапазона затора** (< 40°C или > 85°C): прямой нагрев на 100% мощности для быстрого нагрева
- **В диапазоне затора** (40-85°C): PID-регулятор с ограничением мощности для безопасного и точного нагрева

## Как это работает

### Режим 1: Прямой нагрев (вне диапазона затора)

Когда температура сусла **ниже 40°C** или **выше 85°C**, плагин игнорирует PID и подаёт на ТЭН полную мощность (100% или заданное значение `Max_Output`). Это обеспечивает:
- Максимально быстрый нагрев холодной воды
- Быстрый переход от затора к кипячению
- Отсутствие лишних колебаний мощности

### Режим 2: PID с ограничением (в диапазоне затора)

Когда температура попадает в диапазон **40-85°C**, плагин автоматически:
1. Создаёт свежий PID-регулятор с обнулённой интегральной составляющей
2. Ограничивает максимальную мощность значением `Mash_Max_Power` (например, 50%)
3. Начинает плавно регулировать мощность для точного удержания температуры

Это предотвращает:
- Локальный перегрев и пригар дробины
- Денатурацию ферментов из-за резких скачков температуры
- Неравномерный нагрев затора

### Автоматическое переключение

Плагин постоянно мониторит температуру и автоматически переключается между режимами:

| Температура | Режим | Мощность |
|-------------|-------|----------|
| 20°C → 39°C | Прямой нагрев | 100% |
| 40°C | **Вход в диапазон затора** | PID активируется, ограничение 50% |
| 40°C → 85°C | PID-регулятор | Плавно регулируется до 50% макс |
| 86°C | **Выход из диапазона** | PID деактивируется |
| 86°C → 100°C | Прямой нагрев | 100% |

## Параметры логики

### PID-настройки
- **P** (Proportional): Пропорциональный коэффициент PID. По умолчанию: 117.0795
- **I** (Integral): Интегральный коэффициент PID. По умолчанию: 0.2747
- **D** (Derivative): Дифференциальный коэффициент PID. По умолчанию: 41.58
- **SampleTime**: Время выборки в секундах (2 или 5). По умолчанию: 5

### Параметры мощности
- **Max_Output**: Максимальная мощность при прямом нагреве вне диапазона затора (%). По умолчанию: 100
- **Mash_Max_Power**: Максимальная мощность PID внутри диапазона затора (%). По умолчанию: 50

### Диапазон затора
- **Mash_Min_Temp**: Нижняя граница диапазона затора (°C). По умолчанию: 40
- **Mash_Max_Temp**: Верхняя граница диапазона затора (°C). По умолчанию: 85
