# cbpi4-PIDMash

Плагин логики нагрева котла с PID-регулятором и динамическим ограничением мощности для CraftBeerPi 4.

## Описание

Стандартный PID-регулятор, который автоматически снижает максимальную мощность нагрева при достижении диапазона температур затора (например, 40–85°C). Это предотвращает локальный перегрев, пригар дробины и денатурацию ферментов при использовании мощных ТЭНов.

## Как это работает

- **Вне диапазона затора** (< 40°C или > 85°C): PID работает с полной разрешенной мощностью (например, 100%).
- **В диапазоне затора** (40°C – 85°C): Максимальная выходная мощность PID жестко ограничивается заданным значением (например, 50%).

## Параметры

- **P, I, D**: Коэффициенты PID-регулятора.
- **SampleTime**: Время выборки в секундах (2 или 5).
- **Max_Output**: Максимальная мощность вне диапазона затора (%).
- **Mash_Min_Temp**: Нижняя граница диапазона затора (°C).
- **Mash_Max_Temp**: Верхняя граница диапазона затора (°C).
- **Mash_Max_Power**: Максимальная мощность внутри диапазона затора (%).
