# cbpi4-SmartLogic

Универсальный плагин логики нагрева котла для CraftBeerPi 4. Объединяет быстрый прямой нагрев, бережный PID для затора и плавное кипячение в одном плагине.

## Описание

Вместо того чтобы переключать разные логики для разных этапов варки, SmartLogic автоматически управляет мощностью на всех этапах: от холодной воды до спокойного кипения.

## Как это работает (4 зоны нагрева)

1. **Нагрев воды (до 40°C)**: Прямой нагрев на 100% для максимально быстрого старта.
2. **Затор (40°C - 85°C)**: Включается PID-регулятор с ограничением мощности (например, 50%). Это предотвращает пригар дробины и бережно нагревает затор.
3. **Разгон до кипения (85°C - 98°C)**: PID отключается, снова подается 100% мощности для быстрого доведения до кипения.
4. **Кипячение (> 98°C)**: Мощность автоматически снижается (например, до 60%) для поддержания спокойного, неубегающего кипения.

## Параметры

### PID и мощности
- **P, I, D**: Коэффициенты PID-регулятора.
- **SampleTime**: Время выборки (2 или 5 сек).
- **Max_Output**: Мощность для прямого нагрева вне затора (%). По умолчанию: 100.
- **Mash_Max_Power**: Ограничение мощности PID во время затора (%). По умолчанию: 50.
- **Boil_Power**: Мощность для поддержания спокойного кипения (%). По умолчанию: 60.

### Температурные пороги
- **Mash_Min_Temp**: Начало диапазона затора (°C). По умолчанию: 40.
- **Mash_Max_Temp**: Конец диапазона затора (°C). По умолчанию: 85.
- **Boil_Transition_Temp**: Температура перехода к спокойному кипению (°C). По умолчанию: 98.
